## 3. How to Import Audio into the App

1. **In the Native iOS App (Xcode)**:
   - Place your audio file into `NurseryRhymes/NurseryRhymes/Resources/`.
   - Open `NurseryRhymes/NurseryRhymes/Resources/rhymes_data.json`.
   - Update the entry's `audioFileName` field (e.g., `"audioFileName": "humpty_dumpty.m4a"`).
   - Update `audioDuration` with the actual file length in seconds.
   - Build and run! `AVAudioPlayer` will automatically locate and stream the new track.

2. **In the Web App**:
   - Place the `.m4a` or `.wav` file into `assets/audio/`.
   - Update `assets/rhymes_data.json` with the filename.
   - Refresh the page to test playback with instant seeking and track advancement.
